## Real-World Example

### Scenario: Ghana Summer 2026 Business Internship

**Old Way (Problem):**
- Created TWO separate internships:
  1. "Ghana Summer 2026 - Hybrid ($5,700)"
  2. "Ghana Summer 2026 - Full In-Country ($6,050)"
- Confusing for students
- Duplicate content management
- Cluttered listing page

**New Way (Solution):**
- ONE internship: "Ghana Summer 2026 Business Internship"
- Check both format options in WordPress
- Students see both options clearly on one page
- Choose their preference during application
- Clean, professional presentation

---

## What Students See Now

### When Browsing:
"Oh, this Ghana program has two options:
- Full In-Country for $6,050
- Or Hybrid for $5,700

I can decide which fits my budget and schedule!"

### When Applying:
Application form includes:
```
Preferred Format: ○ Full In-Country ($6,050)
                  ○ Hybrid ($5,700)
```

---

## Migration Steps for Existing Internships

If you have old internships already published:

1. **Update the WordPress Code** (already done above)
2. **Edit Each Existing Internship:**
   - Scroll to "Format Options & Pricing"
   - Check the format(s) you want to offer
   - Enter the price for each format
   - Click Update
3. **Result:** Old internships now show multiple options!

**Time Required:** ~2 minutes per internship

## Summary of Changes

| Feature | Old | New |
|---------|-----|-----|
| **Formats per internship** | 1 | 1 or 2 (student choice) |
| **Pricing** | Single price | Separate price per format |
| **Application Opens** | Not tracked | Full date field |
| **Student visibility** | Hidden | Clear display of all options |
| **Duplicate posts needed** | Yes (for different formats) | No (all in one) |
| **Admin complexity** | Multiple posts to manage | Single post, multiple options |
| **WordPress UI** | Basic dropdowns | Organized sections with styling |
